# Havryluk Clinic — дизайн-система

> Modern dentistry. Thoughtfully personal.
> Графіт + теплий шоколад + слонова кістка. Дорожнеча через простір, типографіку та стриманість.

## 1. Висновки з референсів

Аналіз зроблено на основі знання патернів сучасних dental-сайтів (Tend, Serenity Dental, Austin Dental Co, Clarkson Village Dental, Ajooni Smiles, East Credit Dental) та editorial / wellness-брендів. Живий обхід цих сайтів не проводився. Жоден сайт не скопійовано. Що взято як принципи:

- **Бренд-сайти (Tend та ін.)** — спокійна кольорова палітра без «медичного синього», великі serif-заголовки, людські фото замість стокових усмішок. → Наш hero без «зубів у кадрі», з лікарем або інтер'єром.
- **Сильні локальні клініки** — запис видно завжди: у header, у hero, у sticky-барі на mobile. → Booking CTA на кожному екрані, click-to-call.
- **Слабке місце більшості** — сітки з однаковими rounded-картками і каруселі на 3 відгуки. → Нумерований editorial-список послуг, одна велика цитата замість каруселі карток.
- **Before/after** — найпереконливіший контент, але часто захований. → Окрема секція на повну ширину з доступним повзунком.

## 2. Кольори (`src/styles/tokens.css`)

| Токен | Hex | Роль |
|---|---|---|
| `--color-graphite` | #343434 | основний фон: hero, послуги, лікарі, технології, FAQ, footer |
| `--color-warm-graphite` | #3A3430 | «Про клініку», hover рядків послуг, detail-секції, фото-плейсхолдери |
| `--color-chocolate-graphite` | #332C28 | відгуки, фінальний CTA: теплий контраст |
| `--color-anthracite` | #2F3030 | solid header, мобільне меню, результати, контакти, поля форми, mobile-бар |
| `--color-ivory` | #F3EFE8 | основний текст, primary-кнопка |
| `--color-white` | #FAF9F6 | заголовки |
| `--color-champagne` | #B7A078 | лише мікроакценти: номери 01–08, eyebrow, тонкі лінії, focus |

Ритм секцій: graphite → graphite → **warm** → graphite → **anthracite** → graphite → **chocolate** → graphite → **chocolate** → **anthracite** → graphite. Сусідні секції ніколи не зливаються, і сайт не стає «просто чорним».

Контраст: ivory на graphite ≈ 11:1, `--text-muted` ≈ 7:1, `--text-subtle` ≈ 4.6:1 (лише для підписів), champagne на graphite ≈ 4.8:1.

Hex-коди є тільки в `tokens.css` (і в `theme-color` мета-тегу та `favicon.svg`, де CSS-змінні не працюють).

## 3. Типографіка

- **Cormorant Garamond Variable** (з кириличним набором): H1–H3, цитати, цифри. Курсив для другого рядка заголовка («Уважно й *персонально.*»).
- **Manrope Variable**: текст, UI, кнопки, eyebrow (uppercase, tracking 0.2em).
- Розміри рідинні через `clamp()`, `text-wrap: balance`.
- Шрифти self-hosted, з `unicode-range`: браузер завантажує лише потрібні піднабори.

## 4. Editorial-прийоми

- Номери `01…08` біля кожної секції та в списках.
- Тонкі лінії `--line` (ivory 12%) замість тіней і карток.
- Радіус 2px, без тіней, без glassmorphism і градієнтів як декору.
- Анімації: fade + 14–18px slide, лінії, що «малюються», clip-reveal фото в послугах. Усе вимикається при `prefers-reduced-motion`.

## 5. Фото: art direction

Dark, warm, cinematic, natural skin, soft contrast, одне джерело світла (вікно). Без стокових усмішок крупним планом.

| Слот | Пропорції | Компонент |
|---|---|---|
| Hero (лікар / інтер'єр / відео) | 16:9, full-bleed | `Hero` |
| Послуги (8 шт.) | 4:5 | `ServiceList` |
| Інтер'єр / лікар за роботою | 4:5 | `About` |
| Портрети лікарів | 4:5 | `DoctorCard` |
| До / після | 16:10 | `ResultsSlider` |
| Обладнання + деталь | 3:2 + 4:5 | `Technology` |
| Карта / фасад | 16:9 | `ContactBlock` |

Поки фото немає, `Media` малює плейсхолдер з тими самими пропорціями. Після заміни верстка не зсувається.

## 6. Performance-бюджет (поточна збірка)

- Головна: **~12 KB HTML gzip**, включно з інлайн-CSS.
- JS: лише дрібні інлайн-модулі (header, меню, слайдер, відгуки, форма, reveal). Без фреймворків і бібліотек.
- Hover-прев'ю послуг і FAQ-акордеон зроблені на чистому CSS (`:has()`, `<details>`).
- Зображення: AVIF/WebP, `srcset`, lazy-load, hero з `fetchpriority="high"`.
